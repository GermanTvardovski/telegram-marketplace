# Руководство по режимам работы

## Режимы работы приложения

Приложение поддерживает два режима работы, которые переключаются через переменную окружения `VITE_APP_MODE`:

### 🌐 Режим браузера (Browser Mode) - для разработки

**Настройка в .env:**
```env
VITE_APP_MODE=browser
```

**Особенности:**
- Работает в обычном браузере без Telegram
- Использует демо-данные пользователя
- Не требует авторизации
- Идеально подходит для разработки и тестирования UI

**Запуск:**
```bash
npm run dev
```

Приложение будет доступно по адресу: `http://localhost:3000`

### 📱 Режим Telegram Mini App (Telegram Mode) - для продакшена

**Настройка в .env:**
```env
VITE_APP_MODE=telegram
```

**Особенности:**
- Работает внутри Telegram Mini App
- Использует Telegram WebApp API для авторизации
- Интегрируется с Telegram ботом
- Требует запущенного backend сервера

**Настройка для Telegram:**
1. Создайте бота через [@BotFather](https://t.me/botfather)
2. Получите токен бота
3. Настройте WebApp URL (задеплойте приложение)
4. Установите переменные окружения:
   - `REACT_APP_TELEGRAM_BOT_USERNAME=your_bot_username`
   - `REACT_APP_API_URL=your_backend_url`

**Локальное тестирование Telegram режима:**
```bash
# 1. Установите режим в .env
REACT_APP_MODE=telegram

# 2. Запустите frontend
npm run dev

# 3. Запустите backend (в другом терминале)
cd server
npm install
npm run dev

# 4. Настройте базу данных (если нужно)
cd database
npm install
npm run setup
```

## Различия в поведении

### Browser Mode:
- ✅ Автоматически создает демо-пользователя
- ✅ Работает без backend сервера
- ✅ Симуляция всех функций (платежи, объявления и т.д.)
- ❌ Нет реальной авторизации
- ❌ Нет интеграции с Telegram API

### Telegram Mode:
- ✅ Реальная авторизация через Telegram
- ✅ Интеграция с Telegram WebApp SDK
- ✅ Работа с реальными данными из базы данных
- ✅ Push уведомления
- ❌ Требует запущенного backend
- ❌ Требует настройки базы данных

## Переключение между режимами

### Быстрое переключение:

**Для браузерной разработки:**
```bash
# Создайте или отредактируйте .env.local
echo "REACT_APP_MODE=browser" > .env.local
```

**Для Telegram режима:**
```bash
echo "REACT_APP_MODE=telegram" > .env.local
```

После изменения режима перезапустите dev сервер:
```bash
# Ctrl+C для остановки
npm run dev
```

## Рекомендации

### Для разработки UI/UX:
- Используйте **Browser Mode**
- Быстрый запуск и тестирование
- Отсутствие зависимостей от внешних сервисов

### Для тестирования интеграций:
- Используйте **Telegram Mode**
- Тестирование реального процесса авторизации
- Проверка интеграции с Telegram API

### Для продакшена:
- Обязательно **Telegram Mode**
- Настройте все переменные окружения
- Задеплойте на HTTPS хостинг (требование Telegram)

## Troubleshooting

### Приложение не загружается в браузере:
- Убедитесь, что `REACT_APP_MODE=browser`
- Проверьте, что dev сервер запущен
- Очистите кэш браузера

### Telegram WebApp не работает:
- Убедитесь, что `REACT_APP_MODE=telegram`
- Проверьте, что backend запущен
- Убедитесь, что база данных настроена
- Проверьте консоль на ошибки авторизации

### Переменные окружения не применяются:
- Перезапустите dev сервер после изменения .env
- Убедитесь, что переменная начинается с `REACT_APP_`
- Проверьте, что .env файл находится в корне проекта

## Текущая настройка

По умолчанию проект настроен в **Browser Mode** для разработки:
- Демо-данные пользователя
- Отсутствие зависимостей от backend
- Быстрый старт для разработки UI

Для переключения в Telegram Mode измените `REACT_APP_MODE` в `.env` файле.
