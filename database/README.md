# Настройка базы данных PostgreSQL

## Требования
- PostgreSQL установлен и работает на localhost:5000
- Пароль пользователя postgres: 123

## Установка

1. Установите зависимости:
```bash
cd database
npm install
```

2. Запустите скрипт инициализации:
```bash
npm run setup
```

## Структура базы данных

### Таблицы:
- **users** - пользователи
- **categories** - категории и подкатегории
- **listings** - объявления
- **favorite_listings** - избранные объявления
- **favorite_sellers** - избранные продавцы
- **reviews** - отзывы
- **transactions** - транзакции (включая Tether)
- **orders** - заказы
- **chats** - чаты между пользователями
- **messages** - сообщения в чатах

## Особенности:
- Все временные метки используют TIMESTAMP
- JSONB для хранения изображений
- Индексы для оптимизации запросов
- Внешние ключи для целостности данных
- Начальные данные для категорий

## Подключение в приложении

Для подключения к базе данных в React приложении, создайте backend сервер на Node.js с использованием pg библиотеки.
